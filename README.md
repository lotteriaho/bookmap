# Bookmap mini

Heatmap thanh khoản, bong bóng khớp lệnh, CVD, phát hiện tường lệnh / rút tường / phá tường / hấp thụ / thanh lý,
và lệnh giấy tự động kèm thống kê, cho các mã trên Binance (Futures/Spot). Chạy hoàn toàn trong trình duyệt.

- Mở trang, gõ mã (BTC, ETH, SOL, PEPE…) rồi bấm **Mở**.
- Mở thẳng một mã: `?sym=ETHUSDT`. Dữ liệu mẫu: `?demo=1`.
- Lệnh giấy chỉ để ghi chép, không đặt lệnh thật. Thống kê lưu trong trình duyệt.

Công cụ quan sát, không phải lời khuyên đầu tư.
